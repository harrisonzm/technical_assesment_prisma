# Diagrama de arquitectura

- `architecture.drawio`: diagrama editable; puede abrirse directamente desde **File > Open From > Device** en diagrams.net.
- `architecture.mmd`: fuente Mermaid alternativa; puede pegarse en **Arrange > Insert > Advanced > Mermaid**.
- `class-diagram.drawio`: diagrama de clases editable de la aplicación.
- `class-diagram.mmd`: fuente Mermaid del diagrama de clases.

El esquema representa los límites de Docker Compose, la arquitectura interna por capas, PostgreSQL como fuente de verdad, Redis como caché distribuida, las migraciones y la persistencia de logs.
